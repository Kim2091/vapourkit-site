A five-step quickstart.

1. **Add a video.** Drop a video into the **Source** panel, or click it to browse.
2. **Choose an upscaling model.** Vapourkit ships with several models - pick one that matches your content. See [Included Models](/models/included).
3. **Configure output.** In the **Output** panel, choose a save location and container: MKV, MP4, MOV, or AVI.
4. **Click Start processing.** Vapourkit runs the current filter chain and updates the **Preview** panel as processing progresses.
5. **Review the result.** Click **Compare** to launch the side-by-side viewer, or **Open Folder** to open the output location.

On Linux, **Compare** requires the optional `video-compare` command to be installed separately.
